# Nookblok

**Building the Nervous System for Decentralized Intelligence.**

Autonomous AI Agents on **Base**.

## About

Nookblok is building the nervous system for decentralized intelligence — a coordination layer that enables autonomous AI agents to think, act, and collaborate efficiently on the Base blockchain.

We focus on creating intelligent, onchain agents that cut through the noise and generate real signal in the growing AI ecosystem.

### What We're Building

- **Autonomous AI Agents** — Agents that can operate independently on Base
- **Nervous System** — A coordination layer connecting multiple agents into a unified intelligent network
- **Signal Filter** — Separating valuable intelligence from AI-generated noise
